# Shop Project

A frontend e-commerce practice project built with standalone HTML, CSS, JavaScript, fonts, and image assets.

## Pages

The repository currently includes pages such as:

- Home
- About
- Contact

## Structure

```text
.
├── index.html
├── about.html
├── contact-us.html
├── icon.css
├── js/
├── Fonts/
└── imaje/
```

## Running Locally

No build system is required by the repository structure.

Open `index.html` in a browser or serve the repository with a local HTTP server.

## Status

Archived frontend practice project. It is not presented as a production e-commerce backend.
